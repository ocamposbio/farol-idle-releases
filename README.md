# Farol IDLE — downloads

Instaladores oficiais do **Farol IDLE** (launcher para pokeidle.io). Este repositório contém **apenas os binários** e os manifestos de atualização; o código-fonte é mantido em outro repositório.

- Baixe pela página oficial: https://farolidle.netlify.app/download
- Cada release traz `latest.yml` e `latest.yml.sig` (assinatura Ed25519). O app confere a assinatura e o SHA-512 do instalador antes de atualizar.

Projeto de fã, gratuito e independente. Não é afiliado ao pokeidle.io, à Nintendo, Game Freak, Creatures ou The Pokémon Company.
